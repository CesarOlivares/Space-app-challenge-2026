Sistema visual

Paleta, tipografía, íconos y componentes que usarán las tres partes de la app. Esta página es el piloto de V0: se revisa con el equipo antes de aplicarlo al resto.

01

Paleta

Un único acento. El violeta es solo interfaz: foco, botón principal y marcos. Los colores de datos van aparte (paleta Okabe-Ito, apta para daltonismo) y nunca se usan de adorno, para que un color en pantalla siempre signifique algo. Cada muestra calcula su contraste sobre el fondo; el texto necesita 4,5:1 (WCAG AA).

02

Tipografía

Archivo variable (ancho y peso) para títulos y texto; JetBrains Mono para cifras y rótulos estilo HUD. Ambas con licencia OFL, incluidas en el repositorio: la app no depende de internet.

03

Íconos

Los 23 SVG del kit usan currentColor: toman el color del texto o del acento. Un ícono por lugar: cada uno tiene un uso asignado y no se repite. Los atenuados no tienen uso todavía.

04

Componentes

Contorno fino con el color del panel por dentro, sin bloques rellenos. El único relleno de acento de una pantalla es el botón principal. Las cifras de las muestras son de ejemplo: las reales llevan su fuente verificada (tarea V-10).
